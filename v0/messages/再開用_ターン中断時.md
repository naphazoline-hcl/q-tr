# 再開用メッセージ（ターンが最終報告なしで中断したとき）

> 同じ v0 セッションに、下の「送る本文」を貼る。プロンプト URL はそのセッションで使っているものに
> 置き換える。作業規約は各プロンプト §0.5 と `P0_作業規約.md` に内蔵済みなので、貼り直しは不要。

## 送る本文（P1 セッションの例。URL は使用中のプロンプトに合わせる）

```text
前のターンが最終報告なしで途切れました。最初からやり直さず、既存ファイルの状態を確認して続きから再開してください。
https://github.com/naphazoline-hcl/q-tr/blob/main/v0/prompts/P1_特徴量ライブラリv2.md
未完成のファイルを完成させ、最後に受け入れチェック結果・完了内容・未完了項目・次にやることを簡潔に報告してください。
```

## 補足

- 「続きから」を明示しないと、v0 が最初から作り直して時間を無駄にすることがある。
- 直前の応答で「どのファイルまで書けたか」が分かる場合は、それを本文に1行で添えるとよい。
- 2回以上中断している場合は、プロンプトを分割して「今回はファイル X だけ」と指示する。
