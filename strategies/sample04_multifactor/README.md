# sample04_multifactor — マルチファクター

## 仮説

アルファの源泉はひとつではない。
サイズ・流動性・クオリティ・バリューはそれぞれ別のリスクに対するプレミアムであり、効く局面も違う。
互いに相関の低いものを足せば、予測が安定するはず。

## 処理

sample02 と sample03 の指標を作り直し、3つのブロックにまとめる。
ブロックごとにZ標準化して尺度を揃えてから、ブロック間で等ウェイト合算する。

| ブロック | 中身 |
|---|---|
| サイズ・流動性 | −log(時価総額) + Amihud非流動性 |
| クオリティ | 営業CF/総資産 + ROE + 自己資本比率 |
| バリュー | B/P + 予想E/P |

個別指標をそのまま並べて等ウェイトにしなかったのは、
サイズと非流動性のクロスセクション相関が 0.89 あったことなどが理由。
相関の高い指標、実質的に同じリスクプレミアムを取る指標は、一つのファクターにまとめることが有効である。

なお非流動性はここでも対数を取っていない（sample02 と同じ）。

まとめた後のブロック間相関:

| | サイズ・流動性 | クオリティ | バリュー |
|---|---|---|---|
| サイズ・流動性 | 1.00 | −0.09 | +0.14 |
| クオリティ | −0.09 | 1.00 | −0.38 |
| バリュー | +0.14 | −0.38 | 1.00 |

## 考えたこと・分析

スコアは **+1.14**。狙いどおり、単独より予測が安定した。

| | RankIC | ICIR | スコア |
|---|---|---|---|
| サイズ・流動性 単独 | 0.0047 | 0.043 | +1.05 |
| クオリティ 単独 | 0.0039 | 0.026 | +0.29 |
| バリュー 単独 | 0.0034 | 0.018 | −0.03 |
| 3ブロック合成 | 0.0078 | 0.073 | +1.14 |

ICIR が単独の最良（0.043）から 0.073 に上がっている。

ただし、足せば足すほど良くなるわけではなかった。
モメンタムと低βのブロックを追加すると、こうなる。

| | 回転率 | RankIC | スコア |
|---|---|---|---|
| 3ブロック | 0.030 | 0.0078 | +1.14 |
| ＋モメンタム | 0.055 | 0.0098 | +0.78 |
| ＋モメンタム＋低β | 0.054 | 0.0137 | +0.65 |

RankIC は1.8倍になるのに、スコアは4割落ちる。
追加した2つは単体の回転率が速く（モメンタム0.079、低β0.043）、
全体の回転率を押し上げて、増えた予測精度をコストが食い切ってしまうことなどが原因だと考えられる。
