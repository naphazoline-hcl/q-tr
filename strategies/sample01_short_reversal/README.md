# sample01_short_reversal — 短期リバーサル

## 仮説

1日で大きく売られた銘柄は、換金売りや需給の一時的な偏りで下げすぎていることがある。
偏りが解消すれば翌日以降に戻るので、下げた銘柄を買い、上げた銘柄を売る。

予測対象が市場残差リターンなので、シグナルの側も市場の動きを抜いて測る。

## 処理

1. `raw_return_1day` を読む（前営業日の始値から当日の始値までのリターン）
2. `beta_1day` と `topix_return_1day` で市場の動きを差し引く
   `残差 = リターン − β × 市場リターン`
3. 符号を反転する。下げた銘柄ほどスコアが高い

これだけ。特徴量はひとつで、学習も行わない。

## 考えたこと・分析

スコアは **−6.35**。ただし、この戦略は予測を外しているわけではない。

| | |
|---|---|
| グロス年率リターン | +4.1% |
| 取引コスト | −33.7% |
| ネット年率リターン | −29.6% |
| RankIC | +0.0072（サンプル戦略5本で最高値） |

予測精度は5本の中で最も高い。一方で1日のリバーサルによる銘柄選定は高回転の入れ替えが生じると想定され、それによって生じるコストが問題となっている。

実際に調査をすると、日次回転率 1.337。5分位の順位が毎日ほぼ総入れ替えになるので、
片道10bp = 0.1%のコストが年率33.7%まで積み上がる。

```
年率コスト = 片道0.1% × 日次回転率 × 252営業日
```

シグナルが毎日変わるなら、その分だけ毎日売買することになる。
コスト控除後の成績を見る本コンペでは、**高い予測力を持つシグナルと実現的可能な戦略は別の問題になる**。
配布物トップの README には高速・低速の比較が簡易的にまとめられている。

短期リバーサル自体は残差ベースでグロスSR +0.87 と効いているので、
情報を捨てずに回転率だけ落とせないかを考える余地はある。
シグナル変化率に応じて保有継続をしたり、他の情報を合わせてマルチファクター化して回転率を抑える、などの手法が考えられる。
