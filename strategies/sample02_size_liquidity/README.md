# sample02_size_liquidity — サイズファクター・流動性プレミアム

## 仮説

小型で売買しにくい銘柄を持つ投資家は、売買コスト、情報の非対称性、
アナリストカバレッジの薄さを引き受けている。その対価としてリターンが要求される。
サイズ効果（Banz 1981）と非流動性プレミアム（Amihud 2002）として知られているトピックでもある。

配布ユニバースは TOPIX500 級の大型・中型が中心だが、その内側でも
時価総額の下位と上位の間には差があるはず、というのがここでの前提。

## 処理

1. `prices_daily_quotes` から `Close` と `TurnoverValue` を読む（必要な2列だけ）
2. 発行済株式数を `fins_statements` から as-of で取得する
   - `Date` が tz-aware(Asia/Tokyo) なので `tz_localize(None)` で外す
   - `pd.merge_asof(..., by="Code", direction="backward")`。その時点で開示済みの値だけが入る
3. 時価総額 = `Close × 発行済株式数`。`-log(時価総額)` を日次のクロスセクションでZ標準化する
4. 決算データが無い銘柄は `listed_info` の `ScaleCategory` から作った
   粗い順位で代替。残った欠損は当日のクロスセクション中央値で埋める
5. Amihudの非流動性 = `|リターン| / 売買代金` の60日平均。こちらは対数化せずにZ標準化
6. 2つをどんな比率で足すかは、**Train 期間で学習して決める**（`train.py` → `model.json`：線形回帰）

```
signal = 0.000268 × サイズ + 0.000109 × 非流動性     （サイズを1とすると 1 : 0.408）
```

### サイズだけ対数を取る理由

他の特徴量と足し合わせるため。時価総額の分布は右に大きく歪んでいて（断面の歪度が約 −6）、
そのままZ標準化すると上位数銘柄が分散を独占し、**8割の銘柄が |Z| < 0.5 に潰れる**。
対数化すると歪度は −0.4 程度になる。

| | 歪度 | \|Z\|<0.5 に入る割合 | 非流動性と1:1で合成したときのスコア |
|---|---|---|---|
| `−時価総額` | −6.29 | 81.7% | +0.72 |
| `−log(時価総額)` | −0.39 | 38.5% | +0.90 |

逆に言うと、**単独で使うなら対数を取る意味はない**。採点はクロスセクションランクしか見ないので、
対数は単調変換にすぎず、スコアは +1.177 で完全に一致する。

## 考えたこと・分析

スコアは **+1.12**、日次回転率 0.013。時価総額の順位は1日では動かないので、
売買がほとんど発生せず、コストは年率0.3%で済む。
グロス年率 +3.9% がほぼそのままネット +3.6% として残る。

sample01 との対比が分かりやすい。予測精度（ここではRankICで測定）は sample01 のほうが高いのに、
スコアはこちらが上になる。詳しくは配布物トップの README を参照。

合成の比率は、線形回帰モデルの回帰係数を決定することと同義。
線形に足すだけなのだから、比率は学習で決まる。Train 期間の回帰に任せると `1 : 0.408` になった。


| サイズ : 非流動性 | Train | Valid |
|---|---|---|
| 1 : 0 | +1.94 | +1.18 |
| 1 : 0.408（Train回帰で決定） | — | **+1.12** |
| 2 : 1 | +1.94 | +1.07 |
| 1 : 1 | +1.94 | +1.03 |
| 0 : 1 | +1.63 | +0.57 |


## この戦略の限界

既知のリスクファクターへの露出であって、新しいアルファではない。

実運用では、小型・低流動性の銘柄ほど実際の売買コストは片道0.1%では済まない。
このコンペはコストを一律0.1%と置いているので、**流動性の低い銘柄を持つ不利が反映されていない**。
そのため同じ戦略を現実の口座で運用すると、この成績にはならない可能性がある。

## 改善策

- 特徴量を足して `train.py` を回し直す（係数は学習で決まるので、重みを手で触る必要はない）
- 非流動性の窓を20日や120日にする
