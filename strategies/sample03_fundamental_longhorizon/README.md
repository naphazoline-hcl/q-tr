# sample03_fundamental_longhorizon — 財務ファンダメンタル

## 仮説

決算短信が示す「稼ぐ力」と「財務の頑健さ」は年単位で持続する。
営業キャッシュフローの創出力や自己資本比率は四半期ごとに乱高下しないし、
平均回帰も遅い。だからこれを根拠にした銘柄の優劣は、数ヶ月スケールでしか入れ替わらない。

## 処理

クオリティとバリューをそれぞれ複数の指標で測り、日次のクロスセクションでZ標準化して合算する。

**クオリティ**

| 指標 | 意図 |
|---|---|
| 営業CF / 総資産 | 会計上の利益ではなく実際の現金創出力 |
| 当期純利益 / 自己資本（ROE） | 株主資本に対する収益性 |
| 自己資本比率 | 財務レバレッジの低さ＝下振れ耐性 |

**バリュー**

| 指標 | 意図 |
|---|---|
| 1株純資産 / 株価（B/P） | 純資産に対する株価の安さ |
| 会社予想EPS / 株価（予想E/P） | 予想利益に対する株価の安さ |

- 合算方法
  - 5指標それぞれを、その日の銘柄間でZ標準化する（平均を引いて標準偏差で割る、±3σでクリップ）。
    ROEは%、B/Pは倍と単位がばらばらなので、そのまま足すと単位の大きい指標だけが効いてしまう
  - クオリティ3指標を足したものとバリュー2指標を足したものを、等ウェイトで合算する

```
Z(x)      = (x − その日の平均) / その日の標準偏差   （±3σでクリップ）
クオリティ = Z(営業CF/総資産) + Z(ROE) + Z(自己資本比率)
バリュー   = Z(BPS/株価) + Z(予想EPS/株価)
signal    = クオリティ + バリュー
```

欠損はその日の銘柄の中央値で埋める。0で埋めると、Zスコアの符号次第で
その銘柄が断面の端に飛んでしまう。


決算データの扱いで気をつけた点:

- `Date` は tz-aware(Asia/Tokyo)。`tz_localize(None)` してから `merge_asof` で結合する
- 決算の種類（1Q/2Q/3Q/FY、IFRS/JP）によって欠ける項目が違うので、
  銘柄内で列ごとに `ffill` して直近開示の値を引き継ぐ。未来方向の `bfill` は使わない
- 1株純資産は `BookValuePerShare` 列を使わず `Equity / 発行済株式数` で計算した。
  前者は開示率が38%しかないが、後者なら98.5%の行で値が取れる

## 考えたこと・分析

スコアは **+0.55**、日次回転率 0.033。

このコンペは日次リバランスが前提だが、シグナルがゆっくりしか動かなければ
実際の売買は発生しない。分位が入れ替わらない限り、ポートフォリオのウェイトも変わらないからだ。

```
回転率 0.033/日 → 年間で建玉の8.3倍 → 平均保有期間およそ2.5ヶ月
年率コスト = 0.001 × 0.033 × 252 = 0.83%
```

保有期間はレギュレーションで決まるのではなく、シグナルの速さで決まる。

さらに、クオリティもバリューも単独では弱いのに、双方を組み合わせるとスコアが大きく改善した。

| | スコア |
|---|---|
| クオリティ単独 | +0.29 |
| バリュー単独 | −0.03 |
| 合算 | +0.55 |

両シグナルのクロスセクション相関が −0.38 で逆を向いているためだと思う。
「良い会社」は高く買われているので割安ではない、という当たり前の関係が、実際にこの数値に表れている。
（相関の低いものを合わせる話は sample04 で扱う。）

もう一点。シグナルの更新を月末だけに絞ってさらに回転率を下げようとすると、
グロスの成績も一緒に落ちた（日次+0.37 → 月次+0.22 → 年次+0.08、いずれもグロスSR）。
財務データ自体は四半期にしか変わらないが、開示のタイミングは銘柄ごとにばらばらなので、
更新を止めると新しい決算の反映が最大1ヶ月遅れる。このことが原因となっている可能性があると考えられる。

## 改善案・注意点

- クオリティとバリューの重みを変える。
  - 等ウェイトである必然性はない
  - 学習期間で最適な重みを定めるなど
- 指標を足す。
  - 売上高営業利益率、総資産回転率、配当利回りなど
- 業種内で標準化する。
  - 業種によって適正ROEも適正B/Pも違う
- 決算発表からの経過日数を特徴量にする。
  - 開示直後だけ効くのか、ずっと効くのか

サイズ・流動性などは典型的な**リスクファクター**である。いわゆるオルタナティブリスクプレミア、βの一種であってアルファかどうかは議論が残る。
